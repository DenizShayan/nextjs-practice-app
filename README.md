# Next.js Practice App

A simple learning project built to strengthen my React and Next.js skills.  
This project includes basic pages, navigation, and styling with Tailwind CSS.

---

## 🚀 Features
- Next.js + React setup  
- Tailwind CSS styling  
- Simple Navbar component  
- Pages: Home, About, Tasks  
- Basic form for adding tasks  

---

## 🧠 Purpose
This project is part of my journey to become a stronger front-end developer.  
I’m using it to practice React components, Next.js routing, and clean UI design.

---

## 🛠️ Tech Stack
- **React**
- **Next.js**
- **Tailwind CSS**
- **TypeScript** *(optional, if you used it)*
